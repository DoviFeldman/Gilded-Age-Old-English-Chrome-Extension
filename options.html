About Gilded Age Mode

Transforms modern web text into ornate 1880s Gilded Age English — as if Edith Wharton and Mark Twain were narrating the internet. Elaborate, opulent, high-society parlors, "I daresay", "most esteemed patronage", yet faithful to original meaning.

How it works locally: Content script extracts only visible text nodes (never passwords/inputs). Background service worker sends tiny JSON batches (10 phrases) to your Groq/Cerebras API. Thinking is forced off → sub-200ms response. Original text is kept in memory to restore instantly.

Token saving: Viewport Sipper mode + IntersectionObserver only converts what scrolls into view.

Stored in chrome.storage.sync — persists unless extension uninstall
